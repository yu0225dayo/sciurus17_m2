■ sciurus17 ROS2 Docker 起動手順
  対象: sciurus17/Dockerfile + sciurus17/docker-compose.yml
  用途: ROS2 Jazzy + MoveIt2 環境でロボット制御・GUI を実行する

【前提】
- VSCode のターミナルで Ubuntu (WSL2) を選択して実行すること
- すべてのコマンドは sciurus17/ ディレクトリで実行すること
  cd /mnt/c/Users/yokada/Desktop/robo_ros/sciurus17

--------------------------------------------------
【ステップ1】イメージをビルド（初回のみ・数分かかる）
--------------------------------------------------
docker compose build

--------------------------------------------------
【ステップ2】ワークスペースをビルド（初回のみ）
--------------------------------------------------
docker compose run --rm sciurus17

# コンテナ内で実行
cd /ros2_ws
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
exit

==================================================
  GUI スクリプトの使い分け
==================================================

  sciurus17_gui_demo.py  ... ROS2 不要。GUI の動作確認・デバッグ用。
                             保存済み RGBD を使ってサーバへの送信・把持推定を試せる。

  sciurus17_gui_main.py  ... ROS2 + MoveIt2 必須。実機制御用。
                             カメラ映像取得・アーム移動まで一括操作できる。

==================================================

--------------------------------------------------
【sciurus17_gui_rviz.py の起動（RViz 仮想モード / 実機不要）】
--------------------------------------------------
# ROS2 + MoveIt2 を使い、mock_components で RViz を起動して把持計画を検証する
# 実カメラ不要。保存 RGBD を使って把持姿勢を生成し、仮想ロボットで動作確認できる

docker compose run --rm sciurus17 \
    python3 /sciurus17_m2/ros/sciurus17_gui_rviz.py \
    --rviz-image /sciurus17_m2/client/saved_data/test_20260422_200416 \
    --server-url http://10.40.1.126:8080

# GUI 操作手順:
#   1. 「▶ sciurus17 起動」ボタンを押す → RViz が開くまで 20〜40 秒待つ
#   2. 「▶ カメラ接続」→「フレーム取得」で保存画像を表示
#   3. 画像クリックで物体選択 → 「計算機へ送信・姿勢推定」
#   4. 「▶ 両アームを移動」→ RViz で仮想ロボットが動く

--------------------------------------------------
【sciurus17_gui_demo.py の起動（ROS2 不要）】
--------------------------------------------------
docker compose run --rm sciurus17 \
    python3 /robo_ros/ros/sciurus17_gui_demo.py \
    --demo \
    --demo-image /robo_ros/client/saved_data/test_20260422_200416 \
    --server-url http://10.40.1.126:8080

--------------------------------------------------
【sciurus17_gui_main.py の起動（実機モード）】
--------------------------------------------------
# 事前準備（X11 表示許可 / 毎回必要）
xhost +local:docker

# 実機 + シリアルデバイス接続時（--launch-cmd 必須）
# demo.launch.py = ハードウェア制御 + MoveIt (move_group) + 胸部カメラ を一括起動
# ※ sciurus17_control.launch.py だけでは MoveIt が起動しないためアームが動かない
cd ~/Desktop/test/robo_ros/sciurus17 && docker compose run --rm sciurus17_real \
    python3 /robo_ros/ros/sciurus17_gui_main.py \
    --server-url http://10.40.1.126:8080 \
    --color-topic /head_camera/color/image_raw \
    --depth-topic /head_camera/aligned_depth_to_color/image_raw \
    --info-topic /head_camera/color/camera_info \
    --camera-frame head_camera_color_optical_frame \
    --launch-cmd 'bash -c "source /ros2_ws/install/setup.bash && ros2 launch sciurus17_examples demo.launch.py use_head_camera:=true use_chest_camera:=false"'

# GUI 操作手順:
#   1. 「▶ sciurus17 起動」ボタンを押す → 15〜30 秒待つ（ヘッドカメラも自動起動）
#   2. カメラ接続ボタンを押す（/head_camera/ トピックに接続）
#   3. 画像クリックで物体選択 → 推定 → アーム移動

--------------------------------------------------
【RViz + デモ起動（ターミナル1）】
--------------------------------------------------
docker compose run --rm sciurus17

# コンテナ内で実行
source install/setup.bash
ros2 launch sciurus17_examples demo.launch.py \
    use_mock_components:=true \
    use_head_camera:=false \
    use_chest_camera:=false

--------------------------------------------------
【アームを動かす（ターミナル2 / 既存コンテナに追加接続）】
--------------------------------------------------
docker exec -it sciurus17_ros2 bash

# コンテナ内で実行
source /ros2_ws/install/setup.bash
ros2 launch sciurus17_examples_py example.launch.py example:='move_to_pose'
