■ sciurus17 ROS2 Docker 起動手順
  対象: sciurus17/Dockerfile + sciurus17/docker-compose.yml
  用途: ROS2 Jazzy + MoveIt2 環境でロボット制御・GUI を実行する

【前提】
- VSCode のターミナルで Ubuntu (WSL2) を選択して実行すること
- すべてのコマンドは sciurus17/ ディレクトリで実行すること
  cd /mnt/c/Users/yokada/Desktop/robo_ros/sciurus17

--------------------------------------------------
【ステップ1】イメージをビルド（初回のみ・数分かかる）
--------------------------------------------------
docker compose build

--------------------------------------------------
【ステップ2】ワークスペースをビルド（初回のみ）
--------------------------------------------------
docker compose run --rm sciurus17

# コンテナ内で実行
cd /ros2_ws
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
exit

==================================================
  GUI スクリプトの使い分け
==================================================

  sciurus17_gui_demo.py  ... ROS2 不要。GUI の動作確認・デバッグ用。
                             保存済み RGBD を使ってサーバへの送信・把持推定を試せる。

  sciurus17_gui_main.py  ... ROS2 + MoveIt2 必須。実機制御用。
                             カメラ映像取得・アーム移動まで一括操作できる。

==================================================

--------------------------------------------------
【sciurus17_gui_demo.py の起動（ROS2 不要）】
--------------------------------------------------
docker compose run --rm sciurus17 \
    python3 /robo_ros/ros/sciurus17_gui_demo.py \
    --demo \
    --demo-image /robo_ros/client/saved_data/test_20260422_200416 \
    --server-url http://10.40.1.126:8080

--------------------------------------------------
【sciurus17_gui_main.py の起動（実機モード）】
--------------------------------------------------
# モック（アーム動作なし・動作確認用）
docker compose run --rm sciurus17 \
    python3 /robo_ros/ros/sciurus17_gui_main.py \
    --demo \
    --demo-image /robo_ros/client/saved_data/test_20260422_200416 \
    --server-url http://10.40.1.126:8080

# 実機モード（ROS2 トピック・MoveIt2 が有効な状態で実行）
docker compose run --rm sciurus17 \
    python3 /robo_ros/ros/sciurus17_gui_main.py \
    --server-url http://10.40.1.126:8080

# 実機 + シリアルデバイス接続時
docker compose run --rm sciurus17_real \
    python3 /robo_ros/ros/sciurus17_gui_main.py \
    --server-url http://10.40.1.126:8080

--------------------------------------------------
【RViz + デモ起動（ターミナル1）】
--------------------------------------------------
docker compose run --rm sciurus17

# コンテナ内で実行
source install/setup.bash
ros2 launch sciurus17_examples demo.launch.py \
    use_mock_components:=true \
    use_head_camera:=false \
    use_chest_camera:=false

--------------------------------------------------
【アームを動かす（ターミナル2 / 既存コンテナに追加接続）】
--------------------------------------------------
docker exec -it sciurus17_ros2 bash

# コンテナ内で実行
source /ros2_ws/install/setup.bash
ros2 launch sciurus17_examples_py example.launch.py example:='move_to_pose'
